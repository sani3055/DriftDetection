Abstract
The rapid evolution of cyber threats in modern network environments demands intelligent intrusion detection systems.
This system should be capable of handling complex attack patterns and heterogeneous data distributions. Existing intrusion
detection approaches mainly focus on statistical or temporal ﬂow characteristics. This approach neglects the topological
relationships among network entities and the uncertainty associated with detection decisions. In this work, a Tri-View Hybrid
Architecture with Adaptive Drift-Evidential Learning (TRINITY -IDS) is proposed for robust intrusion detection. Initially,
a Density-Aware Hybrid Resampling strategy based on Cluster-SMOTE and Edited Nearest Neighbor (ENN) cleaning is
applied to overcome class imbalance and improve minority attack representation. An adversarial feature selection mechanism
with gradient reversal learning is used to reduce dataset-speciﬁc feature leakage and enhance cross-domain generalization.
The extracted features are represented through three complementary views: a statistical view using convolutional feature
extraction with channel attention, a temporal view using speciality-token-augmented BiGRU with self-attention for sequential
behavior modeling, and a topological view using Graph Attention Networks (GA T) to capture network relationship patterns.
A dynamic cross-view adaptive fusion mechanism automatically learns the contribution of each representation for individual
samples. In addition, a Dirichlet evidential learning head is used for uncertainty-aware attack classiﬁcation. It estimates belief
and uncertainty values rather than only deterministic predictions. To support evolving network conditions, an online Page-
Hinkley drift detector and experience replay mechanism are incorporated for continual adaptation during streaming intrusion
detection. Experimental evaluation demonstrates that the proposed TRINITY -IDS achieves an overall accuracy of 98.36%,
precision of 98.26%, recall of 98.32%, and F1-score of 98.29%.

1 Introduction
The rapid growth of digital communication has signiﬁ-
cantly increased the dependency on cyberspace for critical
applications [ 1]. Cloud computing and Internet of Things
(IoT) technologies provide data exchange and intelligent
services. This creates new opportunities for cybercriminals
to exploit vulnerabilities in network systems. The mod-
ern cyber-attacks like denial-of-service (DoS), distributed
denial-of-service (DDoS), malware intrusion, ransomware,
botnet activities, probing attacks, and zero-day attacks con-
tinue to evolve with increasing complexity [ 2, 3]. These
sophisticated threats can compromise the conﬁdentiality and
availability of network resources. Therefore, there is a need
to develop intelligent and adaptive cybersecurity solutions to
detect malicious activities in real-time.

Intrusion Detection Systems (IDSs) contribute a signiﬁ-
cant role in cybersecurity [4]. This system continuously mon-
itors network activities and identiﬁes abnormal behaviors.
The traditional IDS approaches are mainly based on rule-
based and signature-based detection mechanisms where pre-
deﬁned attack patterns are matched against incoming trafﬁc.
But, they suffer from limited adaptability against unknown
and rapidly evolving threats. Moreover, the increasing vol-
ume and complexity of network trafﬁc make conventional
detection techniques inefﬁcient for modern heterogeneous
environments. Consequently, intelligent IDS solutions based
on data-driven approaches have gained signiﬁcant attention
to increase detection accuracy and adaptability.
Recently, Machine Learning (ML) techniques [ 5]h a v e
been adopted for intrusion detection due to their capabil-
ity to learn discriminative patterns from network trafﬁc
data. The conventional ML algorithms like Support V ec-
tor Machine (SVM), Decision Tree, Random Forest, and
k-Nearest Neighbor have shown promising performance in
attack classiﬁcation. However, these approaches generally
depend on handcrafted feature extraction and may fail to
capture complex nonlinear relationships present in large-
scale network data. Conversely, Deep Learning (DL) [ 6]
approaches have emerged as effective solutions for automatic
feature learning and intelligent threat detection. Deep neural
like Convolutional Neural Networks (CNN), Recurrent Neu-
ral Networks (RNN), Long Short-Term Memory (LSTM),
Gated Recurrent Unit (GRU), and Transformer models have
proved improved capability in extracting spatial and tempo-
ral patterns from network trafﬁc. The CNN-based approaches
are effective in learning local statistical characteristics. The
Transformer-based models improve long-range dependency
learning through attention mechanisms. However, existing
DL-based IDS approaches still face several challenges like
insufﬁcient handling of class imbalance and dependency on
dataset-speciﬁc features. Also, they suffer from limited cross-
domain generalization and lack of uncertainty estimation.
To address these challenges, A Hybrid Multi-View Intru-
sion Detection System with Adaptive Drift-Evidential Learn-
ing called TRINITY -IDS is proposed for intruder detection.
The major contributions of this work are summarized as fol-
lows:
1. A novel TRINITY -IDS hybrid multi-view intrusion
detection model is proposed. It integrates statistical,
temporal, and topological feature learning for complete
cyber-threat analysis.
2. A Density-Aware Hybrid Resampling and Adversarial-
V alidated Feature Selection strategy is developed
to address class imbalance and improve domain-
independent feature representation.
3. A multi-view representation learning architecture is
applied
4. A Cross-View Adaptive Fusion mechanism is designed
to dynamically combine heterogeneous feature represen-
tations based on sample-speciﬁc importance.
5. A Dirichlet Evidential Learning-based classiﬁcation
approach is incorporated to provide reliable intrusion pre-
diction with uncertainty estimation.
6. An Online Concept Drift Detection and Continual Expe-
rience Replay mechanism is developed for adaptive
learning against evolving cyber threats.
The novelty of TRINITY -IDS does not arise from the indi-
vidual use of CNN, BiGRU, GA T, or attention mechanisms.
It is achieved through their uniﬁed integration with adversar-
ial feature selection, adaptive cross-view fusion, evidential
uncertainty estimation, and continual drift adaptation. Com-
pared to conventional hybrid IDS models, TRINITY -IDS
jointly captures statistical, temporal, and topological trafﬁc
characteristics. It dynamically weights their contributions,
quantiﬁes prediction uncertainty, and adapts to evolving traf-
ﬁc patterns through drift detection and experience replay.

3 TRINITY-IDS
The TRINITY -IDS uses a tri-view hybrid intrusion detec-
tion architecture for effective cyber threat identiﬁcation, as
shown in Fig. 1. Initially, a density-aware hybrid resam-
pling technique based on Cluster-SMOTE and ENN is
applied. This step is used to balance attack categories and
to improve minority class learning. Then, an adversarial
feature selection mechanism is used to remove dataset-
speciﬁc biases and enhance generalization across different
network environments. The extracted features are analyzed
through three complementary modules: a CNN-based statis-
tical view with channel attention, a BiGRU-based temporal
view with self-attention and a Graph Attention Network-
based topological view for capturing network interactions.
These multi-view features are dynamically combined using
adaptive fusion. A Dirichlet evidential learning module is
applied for uncertainty-aware attack prediction. In addition,
an online drift detection and experience replay mechanism is
used for continuous adaptation to change network behaviours
(Fig. 2).

5 Conclusion
In this work, an effective hybrid multi-view intrusion detec-
tion system is proposed. The proposed multi-view learning
architecture captures complementary attack characteristics
through statistical, temporal, and topological representations.
These heterogeneous representations are dynamically com-
bined through the Cross-View Adaptive Fusion module. The
Dirichlet Evidential Learning Head improves detection reli-
ability by achieving uncertainty-aware predictions. Overall,
TRINITY -IDS gives a robust and adaptive solution for intelli-
gent intrusion detection. Future work will focus on reducing
computational complexity\ and optimizing deployment for
edge-based environments.
