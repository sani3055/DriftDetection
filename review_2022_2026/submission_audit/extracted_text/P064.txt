Adaptive network anomaly detection using 
machine learning approaches
Vasudeva Pai1,2, Karthik Pai3,4, Manjunatha S.5*, Srujan Hirmeti1 and Vaibhav V. Bhat1 
Abstract 
This research aims to develop a Network Detection System (NDS) utilizing various machine learning techniques 
to enhance network security through anomaly detection. It evaluates the effectiveness of K-nearest neighbors (KNN), 
gradient boosting, support vector machines (SVM), random forests, and logistic regression in identifying deviations 
from normal network behavior. Furthermore, ensemble learning methods, including voting and stacking techniques, 
are explored to improve detection accuracy. The study proposes and tests a hybrid multi-layered stacking model 
using the CICIDS 2017 dataset, which encompasses both historical and modern attack patterns, providing a compre-
hensive benchmark for evaluation. Model performance is assessed using metrics such as accuracy, precision, recall, 
and F1 score. Special emphasis is placed on feature importance and reduction in dimensionality to enhance model 
efficiency. Additionally, the study addresses the critical challenge of minimizing false positives and false negatives 
for practical deployment. Results indicate that the hybrid ensemble stacking model achieves superior performance, 
with an accuracy of 98.79%, significantly improving network anomaly detection. The research highlights the poten-
tial for further advances through deep learning and real-time detection methodologies to improve network security 
in the future.
Keywords Network detection system (NDS), Ensemble learning, Voting, Anomaly detection, CICIDS2017
1 Introduction
In the modern digital era, where network security is 
paramount, the surge in cyberattacks has highlighted the 
need for more advanced anomaly detection methods. 
Conventional network security solutions, which often 
depend on static rule-based systems, frequently fall short 
in identifying complex and evolving threats [1]. Machine 
learning has emerged as a powerful alternative, offering 
the capability to learn from data and adapt to new attack 
patterns autonomously, without requiring continuous 
human oversight [2]. This field has seen rapid growth, 
with numerous studies demonstrating the effectiveness 
of machine learning algorithms in detecting network 
threats while reducing false positives [3].
This research focuses on detecting a range of network 
attacks, including Distributed Denial of Service (DDoS), 
port scanning, and various denial of service (DoS) attacks 
such as DoS Hulk, GoldenEye, Slowhttptest, and Slow -
loris. Each type of attack presents distinct challenges: 
DDoS floods systems with excessive traffic, disrupting 
service availability, while Port Scanning systematically 
probes network ports to uncover vulnerabilities or open 
services, often serving as a precursor to more severe 
attacks. DoS Hulk is an HTTP-based attack that gener -
ates a massive volume of web traffic to deplete server

2  Literature review
Anomaly detection research in cloud environments has 
grown significantly, emphasizing the need to strengthen 
security in complex and interconnected networks. For 
instance, Hagemann and Katsarou [1] surveyed machine 
learning techniques designed specifically for cloud net -
works, showcasing a wide range of applications in areas 
such as intrusion detection and performance monitor -
ing. Their work underscores the importance of feature 
selection and scalability in ensuring model effectiveness. 
Expanding on this foundation, Shahzad et al. [2] explored 
ensemble learning for multiclass anomaly detection, 
employing methods like decision trees and gradient 
boosting to enhance accuracy and robustness in cloud-
based systems. Gupta et  al. [3] tackled the challenges 
of multi-cloud environments by introducing a feder -
ated learning approach that addresses privacy concerns 
while ensuring robust anomaly detection. Integrated 
with digital twins, their hierarchical federated learning 
framework facilitates collaborative model training across 
multiple platforms without exposing sensitive data, offer-
ing a compelling solution for cloud-based applications. 
In network traffic analysis, Kurniabudi et  al. [6] utilized

Additional research underscores the need to balance

For example, the study “Evaluating the Performance 
and Challenges of Machine Learning Models in Net -

a two-stage intrusion detection framework that inte -

detailed analysis, effectively reducing false positives while 
enhancing detection efficiency. Adnan, Bshara, and Awad 
[10] explored the use of unsupervised machine learning 
for forensic analysis of Advanced Persistent Threat (APT) 
attacks, emphasizing adaptability in detecting APT 
patterns without relying on labeled data. Their study 
addresses key challenges in feature extraction and real-
time threat detection, which are critical for cybersecurity 
forensics. Similarly, Abdallah and Otoom [11] conducted 
a survey on supervised machine learning for intrusion 
detection, comparing different methodologies across 
various environments and providing valuable insights for 
future research directions.
Noto et al. [12] highlighted the effectiveness of ensem -
ble methods in anomaly detection, showing that inte -
grating multiple feature models improves robustness, 
particularly in noisy datasets. Similarly, Vanerio and 
Casas [13] emphasized the advantages of ensemble tech -
niques in reducing false positives, especially in complex 
network environments, and stressed the need for careful 
model selection to optimize detection performance. Shon 
and Moon [14] demonstrated that hybrid approaches, 
which integrate multiple machine learning algorithms, 
offer greater consistency and reliability in anomaly detec-
tion compared to single-model methods. Lok et  al. [15] 
proposed a hybrid model that combines several algo -
rithms to improve flexibility and accuracy in detecting 
unusual data patterns. Alkasassbeh [16] introduced an 
innovative hybrid method that integrates traffic predic -
tion with change point detection, designed to enhance 
real-time anomaly detection in dynamic network envi -
ronments. Wang et  al. [17] conducted a comprehensive 
evaluation of various algorithms and methods used in 
practical anomaly detection applications, addressing 
challenges like scalability, adaptability, and the demand 
for continuous refinement. Their study provides an 
insightful outlook on leveraging emerging technolo -
gies to improve the effectiveness of anomaly detection 
systems.
The authors in [18] presents innovative strategies to 
improve intrusion detection systems (IDSs) by overcom -
ing limitations in existing approaches, building on prior 
studies that have employed machine learning techniques 
such as nature-inspired metaheuristics, Bayesian meth -
ods, and swarm intelligence for attribute selection and 
performance enhancement. The authors proposed an 
XAI-enhanced ensemble model that improves transpar -
ency by explaining detection decisions, while remain -
ing scalable and efficient for real-time deployment on 
resource-constrained IoV gateways [19]. Blockchain 
and Federated Learning (FL) provide complemen -
tary strengths that make them particularly effective for 
secure, privacy-preserving, and collaborative network 
anomaly detection. Federated learning enables multiple 
organizations or distributed devices to collaboratively 
train machine learning models without directly sharing 
sensitive raw data, thereby mitigating privacy and regula -
tory concerns. However, FL alone is susceptible to chal -
lenges such as model poisoning, data integrity issues, and 
a lack of trust among participating entities. Blockchain, 
with its decentralized ledger, immutability, and consen -
sus mechanisms, addresses these limitations by ensuring 
transparent auditing, traceability, and tamper-resistant 
record-keeping of model updates and transactions. The 
synergy of Blockchain and FL thus creates a trustworthy 
ecosystem for collaborative security analytics. This dual 
approach is especially beneficial in three contexts:
• Multi-organization cybersecurity collaborations—
enterprises, governments, and research institutions 
can jointly detect and mitigate large-scale cyber 
threats without exposing sensitive internal data. 
Blockchain ensures fairness and accountability, while 
FL enables knowledge sharing across organizational 
boundaries.
• IoT/edge networks with limited resources—in highly 
distributed environments such as IoT or edge com -
puting, FL reduces the need for centralized data 
transfer, while Blockchain ensures secure coordina -
tion among heterogeneous devices, even in untrusted 
settings.
• Privacy-sensitive sectors like healthcare and 
finance—both domains demand stringent compli -
ance with privacy regulations (e.g., HIPAA, GDPR). 
FL allows cross-institutional anomaly detection with-
out centralizing confidential records, while Block -
chain enforces secure access control and verifiable 
model updates.

to balance efficiency and accuracy, making them suit -
able for real-time detection in resource-constrained 
environments.
3  Methodology
The proposed methodology aims to investigate the 
research hypothesis outlined in Fig.  1. It includes the fol-
lowing different stages:
3.1  Data collection
In the initial step, we loaded and pre-processed the 
CICIDS2017 dataset, a widely recognized benchmark 
for anomaly detection systems. This dataset includes 
an extensive collection of normal and malicious net -
work traffic records. Using the Pandas library, the data 
was imported into a Python environment. We also used 
another dataset, NFS-2023-TE which is a revised version 
of CICIDS2017 for experimental evaluation.

3.1.1  Data splitting
Given the large size of the original dataset, which com -
prises 2,830,744 rows, it was reduced to 60,000 rows 
for this analysis. The data was then divided into train -
ing, testing, and validation sets using the train_test_split 
function from scikit-learn. Specifically, 70% of the data -
set was allocated for training, 20% for testing, and the 
remaining 10% for validation.
3.2  Data preprocess and feature importance
For tree-based models such as Random Forest, feature 
importance was analyzed in greater detail to identify the 
most critical and influential features for network anomaly 
detection. The feature importance attribute of the Ran -
dom Forest model was employed to evaluate the relative 
significance of individual features within the dataset. A 
visual representation of feature importance was created, 
providing valuable insights and aiding in the prioritiza -
tion of the most impactful variables for anomaly detec -
tion. Figure  2 illustrates the top features selected by the 
SelectKBest method for CICIDS2017 dataset, ranked 
according to their importance scores. The x-axis rep -
resents the importance scores, while the y-axis lists the 
corresponding features, with Bwd Packet Length Mean 
and Avg Bwd Segment Size identified as the most signifi -
cant. This analysis facilitates the identification of key fea -
tures that enhance the performance of machine learning 
models. Figure  3 illustrates similar results for NFS-
2023-TE dataset used.
3.3  Model selection
To construct an ensemble model, we selected five diverse 
machine learning algorithms: random forest (RF), gradi -
ent boosting (GB), K-nearest neighbors (KNN) classifier, 
support vector machine (SVM), and logistic regression 
LR). These algorithms were chosen to provide a compre -
hensive combination of methods capable of capturing 
both linear and non-linear relationships. Furthermore, 
including ensemble techniques, such as voting and stack -
ing, ensures the development of a robust predictive 
framework.
3.4  Ensemble learning model
To leverage the strengths of individual models, two types 
of ensemble classifiers were implemented using the Vot -
ing Classifier from the scikit-learn library:
3.4.1  Voting
This method was employed with both hard and soft vot -
ing strategies. The Hard Voting Classifier is particularly 
effective when the base classifiers exhibit similar levels of 
reliability, as it selects the majority class based on discrete 
outputs. The Soft Voting Classifier is advantageous when 
base classifiers provide probabilistic outputs, enabling

aging of predictions.
3.4.2  Stacking
Stacking combines the predictions of multiple base mod -
els, using a meta-model to generate the final output, 
thereby enhancing predictive performance through the 
integration of diverse algorithmic approaches.
3.5  Training and evaluation of model
Each classifier, including the hard voting, soft voting, and 
stacking models, was trained on the training dataset. The 
trained models were then evaluated using the test data -
set, and various performance metrics were calculated to 
assess their effectiveness. The evaluation process con -
sisted of the following steps:
3.5.1  Training individual models
Each base model was independently trained on the train -
ing dataset to establish a baseline performance.
3.5.2  Training the ensemble models
The ensemble methods, including hard voting, soft vot -
ing, and stacking, were trained on the same training 
dataset. The performance of the ensemble models was 
computed by leveraging the outputs of the base models 
as estimators, thereby aggregating their predictive capa -
bilities. Figure  4  shows the detailed architecture of the 
proposed methodology.
