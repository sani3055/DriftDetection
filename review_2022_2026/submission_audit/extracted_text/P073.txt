Ats-dta: adaptive two-stage DDoS detection 
with dynamic threshold adjustment in SDN 
networks
Tianrui Bai1  , Yuan Liu1*, Yiwen Gao1 and Yongbin Zhou1 
Abstract 
Software-Defined Networking (SDN), as a new network architecture, has brought convenience, but also suffered 
from the threat of Distributed Denial of Service (DDoS) attack. However, most existing DDoS attack detection schemes 
for SDN employ only a single detection method, leading to imbalances in detection speed, system overhead, 
and detection accuracy. Even though a few schemes improve detection efficiency and accuracy through two-stage 
detection, they still suffer from low system flexibility and do not support dynamic threshold adjustment. In order 
to resolve these issues, we propose an adaptive two-stage DDoS attack detection scheme with Dynamic Threshold 
Adjustment (ATS-DTA for short), which contains three sub-modules. More specifically, by dividing DDoS attack 
detection into two modules: a conditional entropy-based network traffic anomaly detection phase and a DDoS 
attack detection phase based on machine learning methods. Additionally, an adaptive threshold adjustment module 
is introduced to improve the system’s flexibility. Finally, the experimental results show that our scheme, compared 
to related schemes, not only significantly improves detection accuracy and speed but also supports flexible 
and dynamic threshold adjustment. Specifically, our method achieves an average accuracy improvement of 1.91% 
and a precision increase of 1.23% over baseline methods, underscoring its effectiveness in adapting to complex 
and evolving network environments. These advantages illustrate that our ATS-DTA scheme provides a more balanced, 
efficient, and reliable solution for DDoS detection in dynamic network scenarios.

Introduction
The rapid development of the Internet has significantly 
advanced societal progress and brought immense 
convenience to people’s daily lives. With the substantial 
growth of network users and devices, along with the 
rapid evolution of cloud computing, artificial intelligence, 
and other emerging technologies, the complex traditional 
network architecture can no longer adequately address 
the diverse needs of large-scale users, devices, and 
emerging technologies. Software-Defined Networking 
(SDN) (Chaudhary et  al. 2022), as a novel network 
architecture that separates the network’s control layer 
(responsible for decision-making) from the data layer 
responsible for data transmission. This separation 
enables centralized network control through a controller, 
greatly enhancing network management flexibility and 
efficiency. Moreover, SDN provides open programming 
interfaces, enabling users to program directly through the 
controller to quickly adapt to the varied requirements of 
new services. Thus, this innovative network architecture 
not only ensures network flexibility and efficiency but 
also offers centralized management and programmability,

Nevertheless, security and reliability studies of this new

With the rapid development of computer network 
technology in recent years, the number of network 
attacks has been increasing. Among these attacks, 
Distributed Denial of Service (DDoS) attacks are 
particularly common, and the consequences are 
particularly serious (Awan et  al. 2021). DDoS attacks, 
initiated by hackers or cybercriminals, constitute a type

the system’s performance dropping rapidly or ceasing

attack detection methods in conjunction with SDN’s own

Our contributions
Most existing SDN-oriented DDoS detection schemes 
rely on single-phase detection methods. While statistical 
analysis-based approaches are fast and can quickly detect 
anomalies, they often result in low detection accuracy 
and a high false positive rate. Conversely, machine 
learning-based methods offer superior accuracy but tend 
to incur higher system overhead and slower detection 
speeds. Hybrid approaches that combine these methods 
often lack dynamic threshold adjustment, which limits 
their adaptability in fluctuating network environments. 
Effective DDoS detection requires a solution that not 
only balances accuracy and speed but also dynamically 
adjusts to varying traffic patterns (Setitra et al. 2024). To 
address these challenges, we propose an Adaptive Two-
Stage DDoS Detection Scheme with Dynamic Threshold 
Adjustment (ATS-DTA). This scheme incorporates 
the EWMA-ARIMA Adaptive Threshold Adjustment 
(EWAMA) for dynamic threshold adjustment, enhancing 
both detection accuracy and system flexibility. Unlike 
existing methods, ATS-DTA addresses real-time anomaly 
detection and adaptive response through a two-stage 
framework with dynamic threshold adjustment. The 
first stage facilitates rapid anomaly detection, while the 
second stage, driven by machine learning, ensures precise 
attack confirmation. This approach also minimizes 
unnecessary resource consumption, thereby enhancing 
overall system efficiency. The EWAMA combines the 
long-term trend forecasting capabilities of the Auto-
Regressive Integrated Moving Average (ARIMA) model 
with the real-time anomaly detection and smoothing 
features of the Exponentially Weighted Moving Average 
(EWMA) model. By leveraging this hybrid approach, 
ATS-DTA adapts to changing network conditions more 
effectively than static methods. The key contributions of 
ATS-DTA are as follows: 
(1) Modular Structure for Enhanced Detection: The 
ATS-DTA scheme comprises three interconnected 
sub-modules: the first is an adaptive threshold 
triggering module based on conditional entropy, the 
second is a threshold adjustment module driven by 
the EWAMA, and the third is a machine learning-
based attack detection module. The first module 
detects abnormal network traffic using conditional 
entropy, while the third module validates the 
presence of a DDoS attack by applying machine 
learning models. This modular structure improves 
detection speed and accuracy while minimizing 
false positives.
(2) By combining ARIMA for long-term trend analysis 
and EWMA for real-time anomaly detection, 
EWAMA enables the system to adapt to both 
short-term fluctuations and long-term traffic 
changes, significantly enhancing system flexibility 
and reducing detection delays.These sub-modules 
work together to balance speed, accuracy, and 
flexibility, effectively addressing the limitations 
of existing DDoS detection schemes by reducing 
false positives, minimizing system overhead, and 
adapting to dynamic network conditions.
(3) Advantages Over Baseline Methods: In comparison 
to baseline methods, ATS-DTA offers several 
distinct advantages. First, the dynamic threshold 
adjustment mechanism, based on the hybrid 
EWMA-ARIMA approach, provides superior 
adaptability to fluctuating network conditions, 
which is often a challenge for traditional static 
threshold-based methods. This dynamic adjustment

Relevant theories and techniques
Software sefined network
Software-defined Networking (SDN) is a modern net -
work architecture that redefines traditional network 
structures by separating the data plane from the control 
plane. This separation allows for independent operation 
of the two planes, simplifying network management and 
improving network flexibility. SDN abstracts data plane 
devices and network resources, providing users with 
interfaces to program the network and accelerate net -
work service deployment. Furthermore, by abstracting 
data-plane devices and network resources, SDN recon -
figures the traditional network. It provides interfaces to 
users to enable network programmability and accelerates 
the process of deploying network services. Figure  1 illus-
trates the three layers of the SDN network architecture: 
the application layer, the control layer, and the infra -
structure layer. The control layer is located at the center 
and is responsible for the centralized control of the net -
work. The application layer runs applications and ser -
vices on top of the SDN and connects to the control layer 
through the northbound interface. The infrastructure 
layer consists of SDN switches that perform the switch -
ing function and connect to the control layer through the 
southbound interface. OpenFlow is the most widely used 
southbound interface.

(1) SVM (Support Vector Machine): SVM is a 
powerful classifier that performs classification by finding 
the optimal boundary between data categories. This 
boundary is called a hyperplane, which maximizes the 
distance between different categories. When dealing with 
non-linear problems, Support Vector Machines (SVM) 
use kernel functions to map data into higher-dimensional 
spaces, enabling more complex classification boundaries.
(2) KNN (K-Nearest Neighbors): KNN is a distance-
based classification algorithm that predicts the category 
of a test sample based on the labels of the K nearest 
training samples surrounding it. Specifically, a sample 
is assigned to the most common category among its K 
nearest neighbors. This method is simple and intuitive, 
but can be computationally expensive for large datasets.
(3) DT (Decision Tree): A decision tree is a model 
that infers target values from data features by learning 
simple decision rules. It simulates a series of questions, 
each of which divides the dataset into two subsets and 
recursively builds a tree structure. Decision trees are easy 
to understand and implement, but they can suffer from 
overfitting.
(4) RF (Random Forest): Random Forest is an 
ensemble learning method that constructs multiple 
decision trees and combines their results to make the 
final decision. This approach improves model stability 
and accuracy by introducing diversity among the trees, 
reducing the risk of overfitting.
Models constructed using machine learning methods 
offer a more efficient and accurate solution for detecting 
DDoS attack. This is anticipated to lead to timely 
responses and effective mitigation of these attacks. Each 
of these four models has its own characteristics, ranging 
from simple and intuitive to complex and efficient, 
offering a variety of options for various detection 
requirements and situations.
Related work
The existing SDN-focused DDoS detection approaches 
are broadly categorized into statistical analysis-based and 
machine learning-based schemes.

(1) Detection Programs Based On Statistical Anal -
ysis: Tao and Yu (2013) proposed a two-step DDoS 
detection method based on Shannon entropy and Sib -
son distance, which effectively detects and distinguishes 
between DDoS attacks and flash congestion events. Gio -
tis et  al. (2014) collected and analyzed data to identify 
anomalies in the network using entropy methods. The 
collector module is responsible for periodically gather -
ing data and transmitting it to the anomaly detection 
module. Cui et  al. (2019) proposed a solution to detect 
DDoS attacks using cognitive-inspired calculations based 
on dual address entropy. The statistics collector module 
regularly gathers and computes the frequency of each 
source and destination IP address. The feature calculation 
module determines the destination entropy and source 
address entropy. A DDoS attack is identified when the 
destination IP entropy is lower and the source IP entropy 
is higher than the threshold for normal traffic. Deng and 
Wu (2020) used φ entropy for DoS/DDoS detection and 
demonstrated that φ entropy exhibits greater sensitivity 
compared to Shannon entropy. It can also generate more 
distinctions between normal and abnormal traffic.
Most of the DDoS detection methods mentioned 
above rely on statistical analysis to identify attacks by 
analyzing the statistical characteristics of network traffic 
and comparing them against predefined thresholds. 
While these methods are effective in detecting sudden 
traffic anomalies, they have inherent limitations due to 
their dependence on static thresholds, which restricts 
adaptability to dynamic and evolving network conditions. 
Furthermore, the use of single entropy metrics lacks the 
scalability and robustness required to address hybrid 
DDoS attacks or adversarial environments. These 
limitations often lead to higher false positive rates 
or missed detections, highlighting the need for more 
adaptive and comprehensive detection mechanisms.
(2) Detection Programs Based On Machine 
Learning: Santos et  al. (2020) discuss in detail the 
DDoS detection capabilities in SDN networks using 
machine learning algorithms such as Support Vector 
Machine (SVM) and Random Forest (RF). Ye et al. (2018) 
collect statistical information from flow tables through 
OpenFlow Stats data. Based on this data, they extract 
features such as the growth rate of the source IP , the 
growth rate of the source port, the standard deviation 
of packet counts, the standard deviation of packet byte 
sizes, and the proportion of paired flows. Ultimately, they 
utilize the SVM algorithm as the basis for classification. 
Liu et  al. (2019) propose a DDoS detection method 
based on entropy and a Back Propagation (BP) neural 
network. In this method, an entropy detection algorithm 
is applied at the edge switch for pre-detection. The 
controller then extracts six features to serve as inputs 
for the neural network. The particle swarm algorithm is 
used to refine the parameters of the BP neural network, 
leading to the final DDoS attack detection. Garba et  al. 
(2024) introduces a framework for real-time DDoS attack 
detection and mitigation in SDN-enabled smart home 
networks using machine learning models and SNORT.
The machine learning-based detection method 
above analyzes the characteristics of DDoS attacks, 
extracts relevant traffic features, and integrates them 
with machine learning algorithms for DDoS detection. 
With appropriate traffic characteristics, the machine 
learning-based detection scheme has a higher detection 
accuracy than the statistical analysis-based detection 
scheme. However, traditional machine learning-based 
detection methods often encounter high computational 
and resource overhead due to the continuous execution 
of models and the complexity of feature processing. This 
challenge is exacerbated in large-scale or high-traffic 
network environments, where the constant monitoring 
and analysis of massive data flows can result in significant 
delays and increased system latency. Furthermore, 
frequent model updates and retraining are necessary 
to maintain detection accuracy against evolving attack 
patterns, which further depletes system resources.
In contrast, our two-stage detection framework 
effectively addresses this issue by employing lightweight 
statistical analysis for initial anomaly detection and 
selectively activating resource-intensive machine learning 
models only when necessary. This approach significantly 
reduces system load while maintaining high detection 
accuracy, ensuring improved scalability and real-time 
performance.
Furthermore, due to the computational resources and 
time required for detection algorithms, many researchers 
and developers are now focusing on trigger mechanisms. 
These mechanisms only activate the detection algorithms 
when the trigger conditions are met, thereby reducing 
system resource overhead. Most current DDoS attack 
detection methods rely on periodic triggering. Braga 
et  al. (2010) collected traffic information at fixed 
intervals. However, fixed periodic triggering is inefficient 
in dynamic networks with fluctuating attack patterns, 
reducing adaptability. Guo et  al. (2020) proposed a 
triggering algorithm positioned before the detection 
module, which consumes fewer resources. However, 
its simplistic trigger conditions reduce accuracy in 
identifying complex attacks. Wang et al. (2021) designed 
a two-stage detection system that utilizes dynamic 
thresholds to create a trigger module, effectively reducing 
overall resource consumption. Nonetheless, relying 
solely on packet counts limits precision in diverse attack 
scenarios. Puranik et al. (2023) proposed an entropy- and 
machine learning-based detection scheme for identifying

DDoS attacks. However, the fixed entropy threshold 
reduces flexibility in adapting to dynamic networks. Niu 
et  al. (2023) proposed a two-stage detection method 
that does not incorporate entropy calculations. While 
simplifying computations, it compromises the ability to 
detect subtle traffic anomalies.
In addition to the previously mentioned approaches, 
several other studies have investigated innovative 
methods for DDoS detection in programmable 
networks. For instance, Macías et al. (2021) examines the 
coordination between the control plane and the data plane 
to enhance the effectiveness of DDoS detection. However, 
its reliance on frequent inter-plane communication can 
increase latency and resource consumption, particularly 
in high-traffic environments. Similarly, Musumeci et  al. 
(2022) focuses on the application of machine learning 
techniques in P4 programmable networks to improve 
detection accuracy and efficiency. Lastly, Al  Sadi et  al. 
(2024) proposes an architecture that leverages P4’s 
runtime data plane reconfiguration to minimize data 
transfer between planes. However, their dependence on 
P4-specific features limits adaptability across diverse 
SDN infrastructures. Additionally, Coscia et  al. (2024) 
proposes Anomaly2Sign, a decision tree-based method 
for automatic NIDPS rule generation. While different 
in focus, it provides an alternative perspective for 
integrating machine learning with rule-based intrusion 
detection. In contrast to these approaches, our research 
primarily focuses on the control plane, where we 
implement sophisticated detection algorithms to analyze 
traffic data and identify potential DDoS attacks. By 
centralizing the detection process in the control plane, 
we aim to leverage its greater computational power 
while minimizing interaction with the data plane. This 
allows for efficient and scalable detection without 
overburdening the network’s communication channels

ATS‑DTA scheme
The adaptive two-stage DDoS detection scheme dynamic 
threshold adjustment (ATS-DTA), illustrated in Fig.  3, 
includes an adaptive threshold triggering module, an 
EWAMA threshold adjustment module, and a machine 
learning-based DDoS attack detection module. The 
detection module is invoked only when the features 
extracted from the traffic and the calculated entropy 
meet the triggering conditions in the adaptive threshold 
triggering module. Since the detection module incurs a 
higher computational overhead compared to the trig -
gering module, minimizing the utilization of the detec -
tion module through machine learning methods can 
substantially decrease the system’s computational load 
and enhance system performance. Moreover, the scheme 
includes an adaptive threshold adjustment module to 
dynamically refine thresholds based on feedback from 
the triggering or detection modules. This adaptability 
enhances system flexibility, improves DDoS detection 
accuracy and efficiency, and conserves computational 
resources.
Adaptive threshold triggering module
The adaptive threshold trigger module is the cornerstone 
of this scheme. It not only determines when to activate 
the next phase of the detection module based on the 
machine learning method but also directly impacts 
the detection efficiency and performance of the entire 
system. The trigger module must accurately detect 
abnormal changes in network traffic to promptly and 
efficiently trigger the next phase of the detection module. 
In this trigger module, we propose a network traffic 
anomaly detection algorithm based on conditional 
entropy. This algorithm can detect network traffic 
anomalies by assessing if the change in the conditional 
entropy value of the traffic exceeds a certain threshold.

Algorithm 1 Trigger adjustment module
Algorithm 1 describes the specific trigger module algo -
rithm. When traffic arrives, it first calculates the condi -
tional entropy and message rate. If the traffic at this time 
does not exceed the current threshold, it indicates that 
the traffic is in a normal state. The system then calls the 
EWAMA threshold adjustment module, which fine-tunes 
the threshold based on the most recent traffic data to 
adapt to normal fluctuations in network behavior. If the 
conditional entropy and message rate exceed the cur -
rent threshold, it may indicate a potential DDoS attack. 
The system will then automatically activate the next stage 
of the DDoS attack detection module, which utilizes 
machine learning to determine whether it is a genuine 
DDoS attack or not. If the feedback result indicates a 
real DDoS attack, it suggests that the current threshold 
setting is appropriate. Conversely, if the feedback result 
indicates otherwise, it suggests that the current threshold 
setting may be too strict. At this point, the system will 
call the EWAMA module to adjust the threshold. It is 
important to note that the new threshold should not 
exceed the current threshold.
EWMA‑ARIMA adaptive threshold adjustment module
The EWMA-ARIMA Adaptive Threshold Adjustment 
(EWAMA) combines the strengths of the Auto Regressive 
Integrated Moving Average model for long-term trend 
forecasting and the Exponentially Weighted Moving 
Average model for real-time smoothing and anomaly 
detection. This hybrid approach leverages the predictive 
capabilities of ARIMA while utilizing EWMA to capture 
short-term fluctuations and detect potential anomalies, 
such as those caused by DDoS attacks.

In this section, we will verify and analyze the functionality 
of our proposed scheme by building a simulation 
experimental environment. Additionally, we will compare 
and analyze the performance of our proposed scheme 
and related schemes in the simulated experimental 
environment. The experimental results demonstrate that 
our proposed scheme has higher detection accuracy and 
system flexibility.
Network topology
In the Ubuntu 20.04 LTS environment, Mininet is used

Experimental data set
In this study, we utilized multiple tools to generate 
a diverse range of DDoS attack traffic, ensuring 
comprehensive coverage of attack vectors. Hping3 was 
employed for its flexibility in customizing parameters 
across protocol layers, allowing the simulation of TCP-
SYN Flood, UDP Flood, and ICMP Flood attacks. With 
Hping3, we varied attack frequency, packet sizes, and 
randomized IPs and ports to generate different types of 
DDoS traffic.
In addition to Hping3, we also incorporated tools such 
as LOIC (Low Orbit Ion Cannon) and HOIC (High Orbit 
Ion Cannon), both of which are widely used for simulat -
ing high-volume DDoS attacks. These tools allowed us to 
generate additional traffic patterns that simulate appli -
cation-layer and volumetric attacks, further diversifying 
our dataset.
The training dataset was composed of 100,000 traffic 
samples, including normal traffic and attack traffic 
generated using these diverse tools. The traffic collection 
spanned over 3 h, maintaining a 4:6 ratio between normal 
and attack traffic. By leveraging multiple tools, we 
ensured a broader variety of attack methods, capturing 
different attack behaviors and intensities, thus enriching 
the dataset.

Conclusion
This paper introduces an Adaptive Two-Stage DDoS 
Detection with Dynamic Threshold Adjustment (ATS-
DTA) scheme, designed to enhance the accuracy and 
responsiveness of DDoS detection in dynamic network 
environments. Central to this scheme is the EWMA-
ARIMA Adaptive Threshold Adjustment (EWAMA), 
which combines the strengths of two models: ARIMA 
for long-term trend analysis and EWMA for short-
term anomaly detection and real-time smoothing. 
By leveraging this hybrid approach, the ATS-DTA 
framework adjusts detection thresholds dynamically, 
adapting to the evolving conditions of network traffic. 
This capability not only enhances the timeliness and 
accuracy of detection but also ensures that the system 
remains effective in managing rapidly changing traffic 
patterns.
The ATS-DTA detection process operates in two 
phases. In the first phase, the system monitors key 
indicators such as Packet-in message rates and 
conditional entropy values to identify unusual traffic 
behavior. Based on these observations, the EWAMA 
dynamically adjusts the thresholds to capture deviations 
more effectively. When potential anomalies are detected, 
the second phase is triggered, where machine learning 
models are employed to confirm whether a DDoS attack 
is taking place. Four machine learning models were 
evaluated—support vector machine, K-nearest neighbor, 
decision tree, and random forest—each demonstrating 
strong performance under different traffic conditions.
Future work will focus on expanding the detection 
framework to the data plane by utilizing the P4 
programming language. While integrating ATS-DTA 
with P4 can provide finer-grained packet-level control 
and enable real-time detection and mitigation at the 
network edge, challenges remain in ensuring scalability 
for ultra-large networks and managing resource 
consumption. To address these challenges, future 
research will explore lightweight deployment strategies 
and adaptive load balancing to enhance performance 
in high-traffic environments. Additionally, efforts 
will be made to incorporate detection mechanisms 
for emerging threats, such as low-rate DDoS attacks, 
adversarial machine learning, and multi-vector attacks, 
further strengthening the scheme’s robustness and 
applicability. Moreover, future work will investigate 
distributed deployment strategies of ATS-DTA across 
multiple controllers to improve scalability and fault 
tolerance in large-scale and geographically dispersed 
networks. This approach aims to balance detection 
accuracy and system efficiency while minimizing 
latency in complex network environments.
Furthermore, considering the growing 
importance of secure authentication mechanisms 
in SDN environments, future work may explore the 
incorporation of general network authentication 
techniques to strengthen the overall security 
architecture of the detection framework. Relevant 
studies, including blockchain-based decentralized 
authentication and lightweight trusted execution 
environments, offer valuable references for this 
direction (Liu et al. 2023, 2021).
In summary, ATS-DTA presents a promising 
advancement in DDoS detection by effectively 
combining adaptability, efficiency, and precision. Its 
dynamic threshold adjustment mechanism enables 
the system to adapt to fluctuating network conditions, 
addressing the limitations of static threshold-based 
methods. Additionally, the two-phase detection process 
strikes a balance between computational efficiency 
and detection accuracy, helping to minimize both false 
positives and false negatives. These features collectively 
enhance the system’s flexibility and detection 
capabilities, positioning ATS-DTA as a scalable 
and effective solution for evolving network security 
challenges.
