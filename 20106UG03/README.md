# Project 20106UG03 review-paper submission workspace

Review topic: explainable and drift-aware anomaly detection for cloud and security logs, with AWS CloudTrail as the focal application and network/log-security studies as supporting evidence.

This folder is being prepared for the guide's requirement of 100 journal papers published from 2022 through the search cutoff of 31 October 2026. It is **not a completed 100-paper review**. Candidate discovery, PDF retrieval, full-text eligibility, critical appraisal, completed summary and final inclusion are recorded separately. Existing earlier project packages are preserved but their filenames do not establish completion.

The current package now contains 101 selected primary journal records, 101 distinct readable PDF files, 101 written summaries, a consolidated Word document and a structured review draft. See `README_FOR_GUIDE.md` for the deliverables and exact completion boundaries. This completes the requested collection count, not an exhaustive systematic review or independent critical appraisal. `Review_Records` preserves starting snapshots as well as the updated package validation. Publicly sharing files requires attention to each source licence; subscription access is not permission to redistribute.

The NotebookLM/Gemini Notebook project is `https://notebook.google.com/notebook/c0e448e0-286c-4e4e-aaeb-b63f99ddfcf0`. SciSpace is being used for discovery, but the connected Basic plan displayed a restriction on file downloads. No paid upgrade has been made. No final PRISMA counts, independent human reviewers, inter-reviewer agreement, completed journal submission or Google Drive sharing is claimed.
