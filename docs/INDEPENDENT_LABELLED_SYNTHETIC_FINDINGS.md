# Independent labelled synthetic transfer findings

## What was evaluated

The frozen twenty seed-42 source models were applied, with no target calibration or retraining, to an independently authored, Apache-2.0 synthetic cloud-security sample from `katerina20/cloud-threat-anomaly-lab`, commit `535a2bd48c74ffd1652af7d092ba95b0fcb660b8`. The committed sample contains 801 cloud-neutral events, including 787 source-labelled normal events and 14 source-labelled anomalous events. It is synthetic, not native CloudTrail, and is generated by one source. It is independently authored from the original source deployment, but is not a separately measured real AWS environment.

The generic-to-CloudTrail-shaped adapter is deliberately lossful: source action strings and generic action domains are not AWS event names or AWS service domains, source region values are coarse, and unsupported fields are missing. In particular, the existing behavioural feature code treats missing `readOnly` as false. Target histories begin cold; the target's January 2026 timestamps predate the source model's training period, making this retrospective transfer, not a forward-in-time evaluation. Labels, scenarios, incident IDs and source-provided rolling counters are excluded from features. Three adapter tests check label-independent mapping and schema failures.

## Narrow-history training-cutoff results

| Frozen source input | Synthetic anomalies alerted | Synthetic normal events alerted | Recall | Synthetic normal alert fraction |
| --- | ---: | ---: | ---: | ---: |
| Event ordinal | 14 / 14 | 787 / 787 | 1.000 | 1.000 |
| Event one-hot | 0 / 14 | 0 / 787 | 0.000 | 0.000 |
| Behaviour only | 14 / 14 | 787 / 787 | 1.000 | 1.000 |
| Combined ordinal | 14 / 14 | 787 / 787 | 1.000 | 1.000 |
| Combined one-hot | 10 / 14 | 682 / 787 | 0.714 | 0.867 |

Event-only one-hot produces no alerts, so its alert precision is undefined, not zero or perfect. The all-alert configurations have recall one only because they also flag every normal synthetic event; this is not useful discrimination. These patterns illustrate substantial domain/representation mismatch, not that any model is best in production. The 14 positives and the twenty models sharing this single target sample are far too limited to establish generalizable incident-level performance. The source-generated `is_anomaly` label is not an independently verified production attack label.

No adaptive update or candidate safety policy was evaluated here. The code evaluates frozen event predictions only. Results do not close the original request for a second independently labelled **AWS CloudTrail environment** with representative benign activity.

## Data search and next requirement

Adediran et al. describe an independently annotated CloudTrail sample of 200 events, but state that data are available on reasonable request; its annotation mentions simulator user-agent markers that must be checked for label leakage. No access request has been sent. Splunk and OTRF attack traces contain attack scenarios but do not supply verified event-by-event benign/attack labels and representative benign controls for a conventional FPR/recall calculation. FlAWS is the inherited source corpus, so another copy is not independent.

## Reproduction

The frozen protocol is `docs/INDEPENDENT_LABELLED_SYNTHETIC_PROTOCOL.md`. Code is `scripts/replay_labelled_generic_synthetic.py`, with a label-free adapter at `src/experiments/generic_cloud_adapter.py`. Outputs and source/model hashes are in `results/journal_v5_labelled_generic/`. The output manifest records limitations and the pinned source URL. No attack code, external generator, or AWS account was used. The full local suite passed 102 tests after this addition.
