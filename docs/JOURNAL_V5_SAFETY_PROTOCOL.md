# Exploratory historical-quantile candidate filtering

Declared after inspecting v4 results on these same deployment events; this is a post-hoc exploratory amendment, not preregistration or a blinded independent validation. The goal is to evaluate whether stricter historical-normality screening changes update contamination and downstream detection, not to guarantee safe adaptation.

Reuse the exact 150 v4 feature-matrix stress conditions: five narrow-history, training-offset, seed-42 representations, candidate pool sizes 200 and 2,000, attack fractions 0, 1, 5, 10 and 20 percent, and sampling seeds 17, 42 and 73. Source labels are used only to construct pools and measure outcomes; they are never supplied to the filter, candidate model or guard. April 4 supplies candidate features; the disjoint April 28 session supplies later evaluation. Candidate behaviour features are inherited from the original stream; this is not a live poisoning simulation.

Compute the frozen detector's anomaly scores on the earlier benign calibration set. Set thresholds at the 25th and 50th empirical percentiles using `method=higher`, fixed before examining this amendment's outcomes. Candidates must satisfy the original frozen predicted-normal cutoff and the selected score threshold, with smaller anomaly score considered more normal. Thresholds are not estimated from the attack-containing pool. Report ties and selected counts; percentile thresholds are not assurances of any candidate's true class. Refit only if at least ten candidates remain, using the same historical fitting data and model parameters as v4. Compare unguarded and historical-guarded variants against the saved v4 static, screened and guarded-screened results with identical candidate pools. Guard rejection or insufficient candidates retains the static baseline.

For every policy and condition retain selected total and attack-labelled counts, guard decision, accepted candidates and accepted attacks, and later event confusion counts and metrics. Analyses must explicitly report benign-row exclusion, missed adaptation, acceptance rates, contamination both as counts and fractions, recall and false-positive rate. A lower absolute attack count alone is not proof of improved safety: selection size and guard acceptance can differ. Repeated seeds, policy settings and the reused deployment do not create independent incidents or justify population-level significance. Do not choose or promote a threshold on this same test set, and do not claim this establishes live-operation safety. Preserve all results including negative outcomes.
