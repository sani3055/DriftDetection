# Draft request for the annotated CloudTrail research dataset

**To:** yussuf.ahmed@bcu.ac.uk
**Subject:** Research request for annotated CloudTrail evaluation data

Dear Dr Ahmed,

I am working on research into drift-aware anomaly detection for AWS CloudTrail logs at Vellore Institute of Technology. I read your paper, “Retrieval-Augmented Large Language Model for AWS Cloud Threat Detection and Modelling: Cloudtrail Mitre ATT&CK Mapping” (DOI: 10.32604/cmc.2026.077606), and would like to ask whether the annotated CloudTrail evaluation dataset could be shared for an independent research comparison.

We would also be grateful for guidance on which fields indicate the adversary-emulation tooling, so that we can assess possible label leakage. We would respect any privacy, access, attribution and redistribution restrictions.

Thank you for considering this request.
