# Journal target shortlist

The quartiles and 2023 impact factors below are taken from the attached `JCR IF 2023 (2).xlsx`.
They must be rechecked against the latest Journal Citation Reports and each journal's current aims,
scope, APC, and submission rules before submission.

## Research-based target correction

The attached workbook is a 2023 JCR snapshot and must not be treated as the current quartile
record. In addition, the current official scope page for *Computers & Security* states that the
journal has a moratorium on submissions where AI/ML is a significant component. Because this
project is fundamentally an ML anomaly-detection and drift-monitoring study, it is a high desk-
rejection risk despite its Q1 label in the attached workbook.

Do not use *Computers & Security* as the first submission target unless the supervisor confirms
that the scope policy has changed and the manuscript is explicitly acceptable as a security paper.

## Recommended target

### IEEE Transactions on Cloud Computing — Q1, 2023 IF 5.3

This is the strongest target from the attached list if the paper is framed as a cloud-systems
monitoring and adaptation protocol. It requires stronger cloud-specific technical novelty,
independent temporal validation, realistic threat scenarios, and a clear computational contribution.

## Submission decision

Use **IEEE Transactions on Cloud Computing** as the working target, with **Journal of Cloud
Computing** or **Journal of Information Security and Applications** as practical alternatives.
Keep IEEE TDSC as a stretch target. Do not claim that the paper is accepted or guaranteed to be
Q1/Q2. The final choice must be approved by the supervisor and checked against the current quartile,
scope, APC, and author guidelines.
